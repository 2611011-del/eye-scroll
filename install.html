고개 움직임으로 실제 마우스를 움직이는
데스크톱 프로그램 실행

브라우저 체험은 웹캠으로 미니게임을 조작해보는 데모입니다. 실제로 고개 움직임으로 내 컴퓨터의 마우스 커서를 움직이고, 눈을 감아 클릭하거나 말로 문장을 입력하려면 아래 프로그램을 내려받아 실행해야 해요.

선택
SETUP

설치 및 실행 방법

순서대로 따라 하면 5분 안에 실행할 수 있어요

1

설치 파일 내려받기

아래 다운로드 버튼을 눌러 실행에 필요한 파일을 내려받으세요.

2

압축 풀기

내려받은 압축 파일을 원하는 폴더에 풀어주세요.

3

필요한 패키지 설치

터미널(명령 프롬프트)에서 폴더로 이동한 뒤 아래 명령어를 실행하세요.

pip install -r requirements.txt
4

프로그램 실행

Windows에서는 nosecast_실행.bat 파일을 더블클릭하면 바로 실행돼요. 또는 터미널에서 아래 명령어를 입력하고, 카메라 권한 요청이 뜨면 허용해주세요.

python nosecast.py
5

제어 시작

실행 후 3초간 화면 중앙을 정면으로 바라보면 자동으로 캘리브레이션돼요. 이후 고개(코 위치) 움직임으로 커서가 움직이고, 눈을 잠깐 감으면 클릭/드래그가 실행돼요. "스크롤 업" / "스크롤 다운"이라고 말하면 화면이 스크롤되고, 그 외의 말은 문장으로 자동 입력돼요.
